# Criteri minimi di lab tecnico

- **Avviabilita (30%)**: ambiente riproducibile, nessun file mancante, errori gestiti.
- **Comprensione (25%)**: spiegazione di ragioni e trade-off nella soluzione.
- **Correttezza (25%)**: requisiti soddisfatti, test locali passati, atteso vs reale chiaro.
- **Safety (20%)**: nessun segreto, input validati, auth corretta, azioni esterne controllate.

Ogni sezione deve avere un check di tipo pass/fail e una nota in caso di failure. Distingui chi non completa per errore del workshop da chi non completa per difficolta del partecipante.
