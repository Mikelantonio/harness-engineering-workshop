# Workshop facilitation

1. Elabora un messaggio centrale e un arco narrativo: problema reale -> agent minimale -> decisioni tecniche -> prove -> rischi -> cosa fare domani.
2. Scrivi una slide outline con **un solo concetto per slide**, massimo 3 bullet quando non strettamente necessari; code snippet breve e leggibile.
3. Fornisci speaker notes separati con timing, domanda da porre al pubblico, transizione e segnale di comprensione.
4. Includi almeno una live poll iniziale (conoscenza pregressa), una domanda di previsione prima della demo, una verifica post-lab e un debrief finale.
5. Non usare marchio Google/GDE come attestazione di partnership o certificazione personale. Cita sorgenti tecniche ufficiali senza affermare endorsement.
6. Consegna handout: glossario, cheat sheet, comandi, errori ricorrenti, links canonici, punti di approfondimento.
7. Pianifica inclusivita: alternative per chi non ha accesso API, tempi di lettura, codice con contrasto e font adeguati, task progressivi.
8. Redigi email follow-up e survey orientate ai learning outcomes; non raccogliere PII non necessaria.
