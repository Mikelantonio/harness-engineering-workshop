# Speaker notes standard

Per ogni blocco scrivi:
1. Obiettivo e hook da 30-60 secondi.
2. Una storia o problema developer realistico, preferibilmente con dati sintetici.
3. Demo: comandi e output atteso da leggere; anticipazione errore possibile.
4. Domanda al pubblico e tempo per rispondere (almeno 30 secondi).
5. Collegamento concettuale alla prossima unita.
6. Segnale di recupero: cosa saltare senza intaccare gli outcome se sei in ritardo.

Per gli speaker includi: scheda tecnica, link di backup, piano B, timing, domande ostiche e risposte con riferimenti ufficiali.

Q&A tipiche: In cosa un agent differisce da una chain? Quando serve un multi-agent? Come gestire stato e persistenza? Cosa devo loggare? Come prevenire prompt injection? Quanto costa una demo? Quando scegliere Gemini API vs Vertex AI?
