# Checklist discovery

| Area | Decisione | Default dichiarabile |
| --- | --- | --- |
| Persona | Principianti Python / intermedi / senior | Python intermedio |
| Obiettivo | Demo, apprendimento o produzione | Workshop hands-on |
| Durata netta | Minuti esercitazione esclusi dalle pause | 180 minuti |
| Formato | In persona, remoto, ibrido | In persona |
| Stack | Python, ADK, Gemini API o Vertex AI | Python + Gemini API |
| Accessi | Chiavi, billing, rete, policy aziendale | Credenziali fornite dall'organizzazione |
| Ambiente | uv/pip, OS, editor, Git | venv + pip |
| Output | Repo, slide, labs, cheat sheet, rubric | Repo + labs + note |
| Successo | Evidenza osservabile entro fine sessione | 80% completa lab 1 |

Domande minime: Chi impara? Cosa deve saper fare alla fine? Quanto tempo netto abbiamo? L'ambiente consente chiamate API?

Non trattare un account Google o un accesso API come implicitamente disponibili. Prevedi uno scenario con demo registrata e output campione non sensibili.
